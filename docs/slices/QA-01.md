# QA-01 — 三頁整體驗證與 device gates 清單

狀態：IN_PROGRESS；已執行嵌入與完整 native regression，缺真機／真人接受；不是等第五步才開始。一般 UI 回歸 L1，實際音畫／input timing 驗收屬 L2；依賴各 slice 的 evidence。
Allowed files：`BeatLabUITests/FoundationUITests.swift`、`MetronomeUITests.swift`、`PracticeUITests.swift`；`docs/verification.md`、`docs/mac-acceptance.md`、`docs/release-checklist.csv`；本 evidence／PLAN；ignored TestResults/QA-01。預設沒有 production edits。若驗出 bug，回所屬 slice 修正並重驗，不藉 QA 重寫時計／評分。
Forbidden：為 test 改通關門檻、mock 成功當真觸控／真保存、預填 device／兒童 gates PASS、重設 owner 資料。測試期待值來自既有契約與獨立 fixtures。

Checks：同一 source manifest、原生 build、當前 App/store/core suites與 focused UI；跨三頁首開／推薦／開始停止／返回／重開保存；十關 quarter／eighth／rest／sixteenth／R-L walkthrough；失敗／重複／多打／零輸入／保存失敗；三頁及 sheets 的 light/dark／375×667／最大 Dynamic Type、44pt hit area／contrast／VoiceOver／Reduce Motion；舊與新進度讀取不變。UI test automation 與真機手動 walkthrough 分開記錄。

真機：按 docs/verification 的 BL-002A／G1／G2／G3／G4 所需音訊／輸入／lifecycle／保存／最低與目前 OS 矩陣逐列記錄。至少三位目標年齡使用者短測需監護人同意，不保存身分或影音。未執行即 NOT RUN；設備／解析度不足即 UNKNOWN。可用的 owner phone 截圖只證明那張画面，不等於整矩陣通過。
Failure paths：simulator 啟動／測試選取零項、器材不足、機制缺陷、資料恢復失敗。保留 attempts，零測試不算 PASS。Rollback：恢復 test 設定／自己擁有的 simulator 偏好；不動其他裝置／owner data。
交付：列出哪些改版已接受、哪些 gates 尚未接受。內部 beta 可供驗證，但 G1-G4 不足時不能宣稱正式上架 ready。

## 執行方式（owner 修訂 2026-10-05）

- Foundation gate：UI-BRAND-01 當片 build／三頁與 sheets／小螢幕／大字／dark，保護首頁與共用元件。
- QA-01A：MET-02 當片核對 BPM／拍號／細分／播放辨識、單手操作、小螢幕／大字／dark。語音準備、播放中參數、反覆停止、背景／前景與音訊中斷分別列 evidence。
- QA-01B：GAME-08 當片十關逐關 smoke、選角→選關→準備→開始、星星／鎖定／保存／恢復；store failure fixtures 與 native smoke 分開，不只驗第一關。
- QA-01C：GAME-09 當片真機 timing／音畫／touch response／掉幀。固定同裝置／OS／route／sample rate／課程，保留改前改後原始資料與方法；沿用 G1-G2 budget，不造精度 SLA。Frame intervals、長 stall 和音訊／判分各自量測，不用平均 FPS 或 simulator 順暢代替真機 evidence。
- QA-01 Final：三頁／十關／尺寸／Accessibility／冷啟動／保存與 lifecycle 完整 regression。來源改動後重驗受影響項，前片通過不自動算最終通過。

產品階段為產品化 alpha；現況用「功能完整，產品級 timing validation 尚未完成」。TF-03 前四件事必須有接受證據：三頁 native 與 owner 畫風接受；first-time 實際開始耗時 ≤10 秒（不是自動操作冒充人）；目標年齡第一關理解跟拍；真機聲音／判分 baseline 比較無 regression。工具或觀察不足保留 NOT RUN／UNKNOWN。

Allowed operator aid：`docs/release/playtest-sheet.md`；提供三次匿名短測欄位，保持 NOT RUN。不記錄姓名／身分／影音、不安排外部聯絡，不代 owner 提供監護人同意或填寫結果。

Reviewable candidate artifacts：允許 `docs/design/branding/previews/` 的實際 simulator PNG 與 manifest.json，從 xcresult 複製並記錄來源／hash／mode／尺寸；不作合成成功圖，也不冒充 App Store 已接受截圖。允許 `.governance/evidence/product-alpha-01-recheck.json` 保存 focused runner receipt（linked implementation commit、實際命令／時間／exit code／非宣稱），只作 memory 的持久證據，不修改框架／baseline／hook 或採用狀態。
