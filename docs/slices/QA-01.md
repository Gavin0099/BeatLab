# QA-01 — 三頁整體驗證與 device gates 清單

狀態：PLANNED；一般 UI 回歸 L1，實際音畫／input timing 驗收屬 L2；依賴 UI-BRAND-01、MET-02、GAME-08、GAME-09 的各自 evidence。
Allowed files：`BeatLabUITests/FoundationUITests.swift`、`MetronomeUITests.swift`、`PracticeUITests.swift`；`docs/verification.md`、`docs/mac-acceptance.md`、`docs/release-checklist.csv`；本 evidence／PLAN；ignored TestResults/QA-01。預設沒有 production edits。若驗出 bug，回所屬 slice 修正並重驗，不藉 QA 重寫時計／評分。
Forbidden：為 test 改通關門檻、mock 成功當真觸控／真保存、預填 device／兒童 gates PASS、重設 owner 資料。測試期待值來自既有契約與獨立 fixtures。

Checks：同一 source manifest、原生 build、當前 App/store/core suites與 focused UI；跨三頁首開／推薦／開始停止／返回／重開保存；十關 quarter／eighth／rest／sixteenth／R-L walkthrough；失敗／重複／多打／零輸入／保存失敗；三頁及 sheets 的 light/dark／375×667／最大 Dynamic Type、44pt hit area／contrast／VoiceOver／Reduce Motion；舊與新進度讀取不變。UI test automation 與真機手動 walkthrough 分開記錄。

真機：按 docs/verification 的 BL-002A／G1／G2／G3／G4 所需音訊／輸入／lifecycle／保存／最低與目前 OS 矩陣逐列記錄。至少三位目標年齡使用者短測需監護人同意，不保存身分或影音。未執行即 NOT RUN；設備／解析度不足即 UNKNOWN。可用的 owner phone 截圖只證明那張画面，不等於整矩陣通過。
Failure paths：simulator 啟動／測試選取零項、器材不足、機制缺陷、資料恢復失敗。保留 attempts，零測試不算 PASS。Rollback：恢復 test 設定／自己擁有的 simulator 偏好；不動其他裝置／owner data。
交付：列出哪些改版已接受、哪些 gates 尚未接受。內部 beta 可供驗證，但 G1-G4 不足時不能宣稱正式上架 ready。
