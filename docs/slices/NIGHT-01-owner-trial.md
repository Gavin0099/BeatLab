# 十關候選：醒來後的手機試玩

2026-10-09十關新版Debug 0.1.0（13）已透過Wi-Fi原地安裝。手機鎖定擋住
自動開啟，解鎖後直接打開「拍拍冒險」即可。這次沒有更新TestFlight；
TestFlight裡同號13仍是之前的GAME23版本。

這份清單是待執行的手機驗收，不是已通過的證據。手機保留自己的進度；
模擬器十關煙霧測試使用隔離的 DEBUG 測試資料，不會替手機解鎖。

先完成第一關，觀察正常跳、未打中掉落、接回、下一跳，以及結束切換。
請注意原地等待是否自然、腳是否貼平台、快速補打是否突然換姿勢。
跳躍、落地和承接呈現依實際判定；落地不是另一次需要操作的拍點。
部分通關的結果應保留實際抵達數量，不能把14/16說成全部抵達。

第二關是65 BPM右／左交替，以兩個可觸控區顯示手別；App並不辨識實際
使用哪隻手，左右標示與雙鼓墊是練習指引，判分仍依原有時間匹配；
沒有新增手別正確性判定。開始前先聽四拍；過早輸入不計分，第一拍前原有的 early
判定窗仍保留。停止不保存本次挑戰。
驗證通關後解鎖下一關、重新開啟後進度仍在，以及失敗重試從零開始。

第三、四關是一拍兩格；第五、六關包含等待的休止格。第七、八關是一拍
四格；第九關在大拍之後的半拍操作；第十關整合四格、右左與留白。
這些使用既有關卡 BPM、目標、門檻與保存規則，沒有新增關卡或獎勵系統。
高密度關卡的本機數值與原生畫面檢查不能替代手機掉幀、觸控與音畫同步。

醒來後需確認的體驗選擇：目前其他關卡的聲音仍是原有大拍 click與
實際輸入回饋，只有第一關有原有60 BPM groove。半拍與四格的示範聲音
尚未新增。需以實際試玩判斷孩子能否理解，若要完整跟奏示範，應另開
音訊 slice，而非用動畫計時播放聲音。

待驗收：內建喇叭的節拍與觸控同步、真機連續播放與音訊中斷、背景／前景、
小螢幕／大字、Reduce Motion／VoiceOver，以及孩子第一關是否理解與願意
重試。本機測試、安裝或 TestFlight 可下載，都不代表公開上架條件已接受。
