# 通關與相鄰關卡難度診斷

以下是GAME33安裝時的舊規則診斷。Owner後續已釐清主要卡在一星解鎖，
GAME34另切L2調整前兩關一星，保留精準星星；目前實作／驗證進度見
[GAME34](GAME-34.md)，不再把下方85%／55%當作前兩關的最新一星門檻。

2026-10-09 owner第二關真機回饋：「左右是錯的，進到下關的難度太高？」
左右配置是已確認的呈現錯誤；難度回饋仍需區分解鎖門檻與下一關節奏。
以下是目前程式規則與建議，不是兒童試玩接受或已實作的新門檻。

觀察：十關共用命中率至少85%、Perfect至少55%、多按率至多10%的
通關條件。Perfect由原有±50毫秒規則判定，早／晚但仍在±180毫秒內
會算命中。這些是軟體評分規則，不是量測到的真機延遲／精度。
第一、二關各16個目標，因此至少命中14個、其中9個Perfect，且最多
多按1次，才會拿到一星。只要已成功保存至少一星，下一關便解鎖；
不需要三顆星。停止不保存，零輸入不解鎖，保存失敗也不會提前解鎖。

觀察：第二關65BPM每拍一下，目標間距60/65≈0.923秒；第三關60BPM
每拍兩下，間距0.5秒。雖然BPM變低，操作頻率約變成1.85倍。
左右鼓墊只提供手別指引，現行匹配只看時間，並不辨識或評分實際手別。

解讀：一星解鎖已要求多數拍點達到最窄的Perfect範圍，初學者可能
成功跳過許多小島但仍卡關。第二→第三關同時增加節奏密度，也可能讓
剛解鎖的玩家覺得突然太快。截圖是倒數階段，不能證明實際卡在哪一條
通關規則；需要owner的結果／體感回饋，不能只靠截圖判定因果。

建議（未實作、數值未接受）：將一星解鎖和二／三星精準挑戰分開；
密拍增加較慢的入門練習。前者需要獨立L2評分／保存／解鎖邊界測試，
後者需要L2節奏／目標／場景／音訊驗證。不能只放寬動畫或直接把星星
改成通過，也不能將既有「只允許更快BPM」的設定直接當作慢速模式。

本次GAME-33僅修正實際左右位置；所有門檻、拍點、時間窗、星星及
進度規則均保留。難度修改等owner釐清卡點後再定具體contract。
