Checks／驗收：下列A/B/C分別隨各實作片執行，Final與owner／兒童gate各自記錄，不能合併成單一全綠宣稱。

Gate A（GAME-17前進條件）：原target／epoch／grade不變的回歸與適用真機timing sanity；節拍／視覺跨越由同一資料控制；窄畫面大字不遮擋。
Gate B（GAME-18前進條件）：matched／extra／miss錄到連續動作，不發生pose／大小／腳底突然跳變；input event、音訊cue、render callback證據分開。Profiler輸出按裝置refresh間隔分布、hitch與callback工時描述，先定量測方法／baseline再比較；工具精度不足只做定性結論，不聲稱物理ms同步。
Gate C（GAME-19前進條件）：三角色首關全流程、九關原練習路徑、重開／save-failure、Accessibility與大小／顏色模式通過。
Final：完整原生適用scheduler／matching／persistence回歸、反覆start/stop、interruption／route change、前景／背景、launch冷啟動、實機audio/visual/input與掉幀；保留failure與source/build/device绑定。沿用舊結果需相應hash一致，不能算本輪新通過次數。

Owner／兒童 gate：記首次是否10秒內理解、是否靠聲音跟拍、失誤後是否知道下一步、完成後是否主動想再試，以及角色偏好；需有實際觀察、設備／版本／步驟，未做標NOT RUN，不記孩子個資。工程checks不能替代趣味接受；owner接受與child實測分開報告。
Failure／Rollback：缺硬體、profile timeout、不可見controls、體驗拒絕、timing退化皆明列；停對應gate不推測通過。移除本片新測試hook／debug工具時回復原測試設定，保留錄影／raw receipts；不同slice改動不能被測試rollback抹掉。
Public boundary：此片不自動接受G1-G4、TF-03、公開分發或App Store readiness。尚缺上架流程證據時仍要既有release runbook；不把個人TestFlight可下載當public gate。
