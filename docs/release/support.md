# 拍拍冒險支援

拍拍冒險有自由節拍器與十關節奏冒險。首頁可開始推薦挑戰；準備頁先顯示節奏，遊玩先聽四拍，再跟著拍子按「跳！」。R／L 是手別提示，App 不辨識使用哪一隻手；休止格先等一下。

節拍器可調 BPM、拍號、細分及每拍的重音／一般／靜音。音量為零仍保留內部節拍，畫面及震動提示依設定與裝置能力提供。

聲音中斷或切到背景時會安全停止，回來請重新開始。若沒有聲音，檢查 App 音量與目前輸出裝置；Bluetooth 延遲不同，第一版不提供藍牙精度保證。

課程進度與設定儲存在本機。刪除 App 或明確重設進度會移除相應資料，重新安裝不能保證還原。

遇到問題請至 [BeatLab Issues](https://github.com/Gavin0099/BeatLab/issues)，提供 App 版本、裝置型號、iOS 版本及可重現步驟。請勿在公開 issue 留下孩子姓名、私人資料或敏感截圖。
