# 第一關短測紀錄

由 owner 在取得監護人同意後進行。使用目標年齡範圍的三位使用者，每次約五分鐘；只記匿名 A／B／C，不保存身分或影音。

給孩子的開場：「請找一個可以開始玩的地方。」先不指按鈕；記從看到首頁到指出或按下開始的時間。接著玩第一關，觀察是否能理解先聽四拍、跟拍跳與休止等待。結束詢問：「你覺得什麼時候要跳？還想再玩一次嗎？」記原意，不引導回答。

另記候選 source／build、手機型號、iOS、音訊路徑、是否用 VoiceOver／Reduce Motion／大字。首次入口目標為 ≤10 秒；理解／想再玩需保留觀察結果，不能由自動 UI test 代填。
